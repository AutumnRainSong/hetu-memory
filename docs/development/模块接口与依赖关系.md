
## 核心接口（Storage SPI 六原语）

```ts
interface StorageProvider {
  get(id: NodeId, opts?: { includeArchived?: boolean }): Promise<NodeRow | null>;
  put(node: ImmutableNode, cas?: { expectedRevision: RevisionId }): Promise<PutResult>;
  // PutResult = { ok: true } | { ok: false, error: 'STATE_CONFLICT'|'STUB_IMMUTABLE'|... }
  query(q: BM25Query | MetadataQuery): Promise<Hit[]>;
  graphTraverse(from: EntityId, budget: TraverseBudget): Promise<Subgraph>; // MVP: throw UNIMPLEMENTED
  vectorSearch(v: Float32Array, budget: number): Promise<Hit[]>;            // MVP 阶段一: throw UNIMPLEMENTED
  blobRef(hash: ContentHash): Promise<BlobHandle>;
}
```

## 关键不变量（存储层强制，非应用层）

1. 链尾唯一：`UPDATE nodes SET superseded_by=? WHERE id=? AND superseded_by IS NULL` 条件写，影响行数=0 即 CAS 失败
2. 节点不可变：无 UPDATE content 路径；只有 INSERT 新 revision
3. Purge Ledger 先行提交，级联删除可从对账恢复
4. Writer 队列单写者；CAS 冲突方 rebase 后重试

## 跨模块契约

| 生产者 | 消费者 | 契约 |
|---|---|---|
| WriteGate | Storage | 意图（ADD/UPDATE/...）已按调用者模板裁决；存储层只执行 |
| Outbox | Digest/Index/GC Workers | 幂等键 (kind, entity_id, seq)；至少一次投递 + 消费端幂等 |
| PurgeLedger | 洛书导出 | purge_markers = ledger 全量投影（导出版脱敏去 operator） |
| RecallEngine | ContextAssembler | Hit{node_id, revision_id, score, scope}；scope 已过滤 |
| EmbeddingWorker | VectorSearch | 向量带 model_version；维度不匹配拒载 |
