# 河图 HeTu · 第一版研发计划

> 基线：主规格 v1.4 收敛定稿 · 洛书 v0.3 · 遵循《第一版研发启动任务书》五阶段划分
> 原则：**先端到端最小闭环，再逐步增加复杂能力**；每阶段有 QA 可验证的出口

---

> **2026-11-25 校准**：按《下一阶段研发执行任务书》统一里程碑命名。
> 原 M1 拆分为 M1-A（数据模型）/ M1-B（Storage Engine）/ M1-C（业务闭环），
> 多 Agent 共享与共识属核心能力，不因 Agent 调度延后而推迟。

## 里程碑总览（校准后）

| 里程碑 | 内容 | 状态 |
|---|---|---|
| **M0** | 工程骨架、CI、六项 P0 决策 | ✅ 完成 |
| **M1-A** | Scope 持久化、RevisionId 分离、安全迁移与回滚 | 🔧 Rev4 待独立复审 |
| **M1-B** | SQLite Storage Engine（CAS / 事务 / Outbox / 并发） | 🔧 已实现，Review R1 定点修订中 |
| **M1-C** | Remember → Persist → Recall 业务闭环 + 权限执行链 | ⏳ |
| **M2** | Minimize / Forget / Purge 生命周期与 Purge Ledger | ⏳ |
| **M3** | RAW / Outbox / Session Digest / 背压 | ⏳ |
| **M4** | 洛书 / Proposal / 讨论裁决 / Embedding / HNSW / 发布 | ⏳ |

> **范围边界**：河图负责多 Agent 记忆协同，不负责 Agent 调度与运行。
