# 河图 · 研发验收标准

> 每阶段的出口门禁；QA 独立判定，Stop-ship 权限适用。

## 通用门禁（所有阶段）

- [ ] 行为矩阵相关格全部测试通过（夹具驱动，无内联期望）
- [ ] 新增代码无绕过写入闸门的写路径
- [ ] 设计文档与实现一致性 diff 无未解释差异
- [ ] 错误码使用与注册表一致

## 阶段一（最小闭环）验收

**功能**：
- [ ] remember 写入成功并持久化（Node/Revision/Provenance 完整）
- [ ] recall 按 Owner/Project/Agent/Scope 正确过滤
- [ ] 服务重启后记忆仍在（持久性测试）
- [ ] 不同 Owner 私有记忆互不可见（隔离测试）
- [ ] introspect 返回正确权限位
- [ ] QA 自动化测试可一键复现全部上述行为

**指标**：写 P95 ≤ 50ms（无向量）；recall 基础检索 P95 ≤ 80ms（BM25 路径）

## 阶段二（生命周期）验收

- [ ] supersede 链：链尾唯一性并发测试（N agent 并发 supersede → 单链）
- [ ] Minimize→Revive：content_hash 一致；Minimize→Purge：归档零残留
- [ ] Forget：recall 不可见 + 邻居边/备份/导入均不复活
- [ ] Purge Ledger：五处残留断言（DB/边/FTS/HNSW/blob）全空 + kill -9 任意时刻对账收敛
- [ ] 不可达组合可达性属性测试通过

## 阶段三（后台）验收

- [ ] RAW 背压：Digest 全挂 + 持续写入 → 零未归档 RAW 删除（底线断言）
- [ ] 三级阈值行为正确（80 告警 / 95 暂停后台 / 100 拒写且 recall 正常）
- [ ] 重启后 watermark 与 stuck 批恢复一致
- [ ] Session Digest 幂等（重复消费不重复生成）

## 阶段四（MVP 毕业考）

- [ ] 毕业考闭环：记住→跨会话召回→Forget→不再出现→洛书导出→Restore→Purge 内容不复活
- [ ] 洛书 round-trip + 随机删节点 fuzz 通过；Restore/Merge 权限判定一致（属性测试）
- [ ] Proposal 异常场景（等待/过期/重验/并发预留）通过
- [ ] 性能四目标：Recall P95 ≤150ms / Persona 装配 P95 ≤10ms / 增量索引 ≤1s / 后台影响 ≤10%（冷/热/全链路分列）
- [ ] 权限泄漏 QA（200 条级）零失败

## 每阶段提交物

可运行版本 · 测试报告 · 未完成事项 · 风险清单 · DDR 状态更新
